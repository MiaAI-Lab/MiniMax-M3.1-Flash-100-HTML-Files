Setting a word along a path is the oldest typographic trick after the drop cap, and it is still the most convincing, because the curve of the line enters the word and changes how it is read. A word on a rising diagonal sounds like it is going somewhere.

SVG's textPath element does the geometric work: the browser measures the path, lays the glyphs along it, and rotates each one to the local tangent. The letters remain live text — selectable, searchable, and scalable without redrawing anything.
