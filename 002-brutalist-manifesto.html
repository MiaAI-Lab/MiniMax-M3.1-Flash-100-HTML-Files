Design Without apology

Every year the interface industry invents a new temperature. Every year the work gets softer, quieter, more apologetic — a wall of rounded rectangles that politely declines to have an opinion.

We are against it. A manifesto for loud, flat, typographically violent design. Raw material means the material is the message: the grid is visible, the borders are real, and the words are set at the size they deserve.

Brutal

Hard edges. Flat fields. No gradient that apologises for itself. Structure you can read from across the room.

Loud

Scale is a tool. A heading that fits the box is a heading that says nothing. Set it until it breaks, then let it wrap.

Honest

No glass, no bloom, no fake depth. Every element on screen is doing exactly one job and admitting to it.

Made

Hand-composed, not templated. If it looks like a CMS filled it in, it was wrong from the start.

04

Eleven laws

01The border is honestIf a line separates two things, it is four pixels and it is black. No shadows pretending to be lines, no gradients pretending to be space.
02Type carries the layoutNever ask the grid to do what a good typeface can do. Set the headline big enough to be a structural element and the page will arrange itself around it.
03Colour is load-bearingOne red, one yellow, one blue, one green. Each is a beam. Each block is a room. Nothing is decorative.
04Motion must explainA hover that moves the element is decoration. A hover that shows where the element came from is communication. Choose the second.
05Whitespace is structuralEmpty space is not wasted space. It is the pause that makes the loud parts legible. Remove it and the page becomes a poster.
06Never centre everythingLeft-align the body. Right-align the metadata. Centre only the single line that has to be centred. Alignment is a hierarchy.
07The grid is visibleLet the columns show through. A reader should be able to feel the structure the same way they feel a table edge.
08Ship the weird ideaThe slightly wrong thing is the thing that gets remembered. Perfect is forgettable in a scroll of a hundred perfect pages.
09No more than two weightsRegular and black. If a third weight appears, something is wrong with the hierarchy and the fault is in the copy, not the font.
10Sound is optional, silence is notNothing autoplays. Nothing chimes. The page waits for you like a person who has read the room.
11Print itIf the layout falls apart on paper it was never a layout. It was a screen pretending to be a poster.
