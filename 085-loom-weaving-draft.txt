The cloth is computed, not drawn: for every crossing the warp thread's shaft is looked up from the threading, the treadle for that pick is looked up from the treadling, and the tie-up says whether that treadle lifts that shaft — so the drawdown on the canvas is the true multiplication of the three grids, coloured warp indigo where the warp is on top and weft ochre where the weft is. Interaction: clicking a cell in the threading moves that warp thread to another shaft, clicking a cell in the tie-up lifts or drops that shaft for that treadle, and clicking a cell in the treadling changes which treadle is pressed for that pick, with the drawdown redrawing after every change; the four preset buttons set plain, two-over-two twill, basket and satin; Weave the cloth advances pick by pick with a red marker on the current pick. Responsive: the draft panel and the two-column section stack under 900px.

DESCRIPTION:
A working four-shaft loom. The cloth on the canvas is the true product of three grids: the threading says which shaft each warp thread is on, the tie-up says which shafts each treadle lifts, the treadling says which treadle is pressed for each pick, and at every crossing the code works out whether the warp or the weft is on top. Change any one of the three and the whole cloth changes — which is exactly why a weaver's draft is the design and the cloth is only the consequence.

MAJOR VISUAL TECHNIQUES:
- Drawdown computed from the threading, tie-up and treadling grids
- Warp and weft cell shading that reads as interlaced thread
- DOM grid editors built from 12-pixel cells with a hairline gutter
- Longest-float measurement in both directions
- Pattern detection that names plain weave, two-over-two twill or a free draft
- Pick-by-pick weaving animation with a red current-pick marker

INTENDED INTERACTION MODEL:
Weave it. Edit the three grids by clicking, use the presets, and run the cloth pick by pick while the drawdown builds up underneath.
